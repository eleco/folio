FOLIO CHROME EXTENSION

Unzip this folder. Open chrome://extensions, enable Developer mode, select Load unpacked, and select this folder. Pin Folio. Click it on any http/https webpage. Sign into your ChatGPT account if prompted. Open the same Folio address on your phone.

Private URLs are stored in your personal collection. This extension only reads the active tab when clicked. It saves URLs and titles, not full article copies.
